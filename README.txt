ENVIRONMENT
  Simulator : Webots R2025a (Windows 11); robot model TurtleBot3 Burger (differential drive, LDS-01 LiDAR)
  Python    : 3.12.10 (Webots controllers and offline scripts); no ROS, no Gazebo
  Packages  : see requirements.txt  ->  py -3.12 -m pip install -r requirements.txt
  Hardware  : standard Windows 11 PC, 12-thread CPU, no GPU needed
  Run all commands from the project folder (the one that contains this README).

FOLDERS
  worlds/        Webots worlds (.wbt)
  controllers/   Webots Python controllers (each folder holds <name>.py and odometry.py)
  notebooks/     offline Python scripts (planning, PID, PSO, neural network, plots)
  data/          saved maps, paths, LiDAR dataset, trained network weights
  report/        figures and text results used in the report

COMPONENT A  (single robot, worlds/component_a.wbt, 4 x 4 m arena, 6 boxes)
  A1 Perception and mapping
     Webots: open worlds/component_a.wbt (controller nav_controller: wanders, fuses wheel odometry with the
     compass, builds a log-odds occupancy grid). Runtime ~150 s simulated (about 10 s at fast-forward).
     Offline: py -3.12 notebooks/plot_map.py ; notebooks/camera_lidar_fusion.py (OpenCV box/wall detection
     and camera-LiDAR fusion on data/camera_start.png and data/scan_start.npy).
  A2 Planning:   py -3.12 notebooks/planning.py     (Dijkstra and A* on the saved map data/occupancy_map_final.npy; a few seconds)
  A3 Kinematics and PID: py -3.12 notebooks/pid_tuning.py    (offline simulation, gain tuning, path following; ~10 s)
  A4 Closed loop in Webots: open worlds/component_a_follow.wbt (controller follow_controller), press play,
     wait for "FINISHED" (~30 s simulated); then py -3.12 notebooks/plot_closed_loop.py

COMPONENT B  (four robots)
  Multi-robot world: worlds/component_b.wbt (generated by notebooks/make_world_b.py from component_a.wbt)
  Consensus (rendezvous): open worlds/component_b_consensus.wbt, run 45 s simulated, then
     py -3.12 notebooks/plot_consensus.py
  PSO task allocation:      py -3.12 notebooks/pso_allocation.py          (brute-force check + 20 runs; about a minute)
  Neural network:  data collection: open worlds/component_a_collect.wbt (3600 s simulated, a few minutes at
     fast-forward, writes data/lidar_dataset.npz); training: py -3.12 notebooks/nn_train.py
  Centralised vs distributed:  py -3.12 notebooks/central_vs_distributed.py

NOTES
  - Close image viewers before re-running scripts that save figures (Windows locks open files).
  - The data/ folder already holds the results used in the report, so every offline script runs without Webots.
  - Set MPLBACKEND=Agg to save figures without opening plot windows.
