# ASR700: Intelligent Autonomous Robotic Systems Project

Autonomous Systems and Robotics 700 assignment (Richfield).

- **Component A:** Perception, motion planning and PID control for a mobile robot (Webots + Matplotlib)
- **Component B:** Multi-agent swarm system with learning-based decision-making (Webots + Matplotlib)

Platform rule: Webots and Python libraries only. ROS and Gazebo are not used.

## Repository layout

| Folder | Purpose |
|---|---|
| `worlds/` | Webots world (.wbt) files |
| `controllers/nav_controller/` | Component A robot controller |
| `controllers/swarm_controller/` | Component B swarm controller |
| `data/` | Sensor data and datasets |
| `notebooks/` | Python/.ipynb analysis and Matplotlib plots |
| `report/` | PDF report |
